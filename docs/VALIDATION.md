# 支持与验证边界

本项目采用固定版本和失败时停止的策略。版本匹配也不等于完成现场验收。默认 MuMu；显式 PC 是旧路径、绝不自动回退。见 [固定清单](MUMU-DAILY.md) 和 [证据命令](MUMU-EVIDENCE.md)。

| 范围 | 已有验证 | 未验证或受监督部分 |
| --- | --- | --- |
| 通用状态机 | 游戏日、防重锁、提交前账本、未知结果阻断、证据绑定、只读审计、精确进程分类的离线回归 | 跨机器、跨界面变化的运行可靠性 |
| 明日方舟 v6.22.0 | 固定任务计划、taskid/uuid/worker/哈希及 planned 后缀恢复；实测监督锁屏 ADB | 下次仍须现场核验主页；TL-9 已结束，禁止自动选替关 |
| 少前 2 v2.8.4 | 任务白名单、共享锁与分阶段账本的离线测试 | 旧 v2.8.4 适配器不跨版。v2.8.6 的 Android ADB 已有监督实测，新 ADB 探测/单步校验与日常凭据均单测验证，不代表完整锁屏运行、无人值守或桌面适配已实测；最高可扫荡关等仍需核验 |
| 终末地 v3.1.0 | 目标库存、环境/物资独立阶段；新增 50 项离线回归覆盖礼物、信用、转交、尾款和中断边界 | 此为旧 PC 验证；默认 MuMu 仅有安装/启动证据，未验收登录后日常及锁屏。信用、选材和尾款等须逐项验收 |
| 官方下载器 | 元数据、大小、SHA-256、HTTPS 域名、ZIP 穿越/链接/设备名/容量检查的离线测试 | 三个完整 release 的下载→安装→启动链路未重新验收 |
| 技能与预览 | 三个技能结构检查；只读预览不应联网、写账本、加载 SDK 或启动进程 | 各助手的自动发现与安装机制没有通用保证 |

公开基线的回归命令为：

~~~powershell
python -m unittest discover -s tests -v
~~~

公开基线在 Windows / Python 3.12 上通过 235 项离线测试；其中两项新增覆盖许可证文件仍接受凭据扫描，进程分类测试另修复了长路径下的命令长度问题。测试使用临时文件、合成回调和模拟 API，不会证明 UI 识别或资源消费现场正确。原生资源哈希只证明文件匹配，不保证游戏规则未变。

**尚未完成从全关闭状态启动、三款游戏全部日常完成、再退出的无人值守端到端验收。** daily_pipeline 管理基础串行生命周期，补充步骤仍需监督调用与核验。

截图格式、哈希、API connected 和回调成功都不能单独证明已登录、任务完成或尾款到账。无法确认时保留 partial/unknown；资源受限为 recorded_limited，不计全部完成。

历史兼容保留了终末地新增审计从 2026-11-19 游戏日起生效的切换点；这不是允许重放旧日任务的开关。同一账号只能选一个工作副本，迁移前自行核对本地历史，历史记录不随公开源码提供。

## 新增监督模块

少前2商城、班组、调度室与热寂悖论物资模式，以及终末地谷地三仓使用独立监督账本。测试使用合成图片和合成余额/库存，不连接游戏。覆盖免费商品与同位置收费商品、前台切换、已领、提交未知、周档逐档去重、活动关闭/零密钥、现有报价复用、低库存、部分装箱、尾款未到账。

这些模块没有自动识别/点击后端。外部人工完成只能作为流程经验；下次周重置、不同班组等级与阵容、活动其它批次数及新脚本完整覆盖须独立验收。旧综合审计不应以新增监督账作原生执行回执；不要伪造旧回执来关闭。

本次公开版本在 Windows / Python 3.12 离线回归：325 项通过；本批新增90项。测试不操作游戏，不代表自动输入实机验收。
